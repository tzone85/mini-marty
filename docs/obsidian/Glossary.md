# Glossary

| Term | Meaning |
|---|---|
| Virtual Marty | The browser-side stand-in for the real Marty robot. Class `VirtualMarty` in `features/marty/virtual-marty.ts`. |
| Command Queue | FIFO queue of `MartyCommand` resolved one at a time. Class `CommandQueue`. |
| Clock | Time abstraction with `RealClock` for prod and `FakeClock` for tests. |
| Pyodide | CPython compiled to WebAssembly. Loaded from a CDN. |
| `martypy` | Python module name. In-browser version is generated by `MARTYPY_MODULE_CODE` and bridged to `VirtualMarty`. |
| Blockly | Google's drag-and-drop block library. |
| R3F | React Three Fiber. A React renderer for three.js. |
| CSP | Content Security Policy. Set in `middleware.ts` with a per-request nonce. |
| LCP / CLS / INP | Web Vitals reported through `startWebVitals`. |
| ADR | Architecture decision record. See [[Decisions]]. |
| Coverage gate | The 80% line / statement / function / branch threshold enforced by `vitest.config.ts`. |
